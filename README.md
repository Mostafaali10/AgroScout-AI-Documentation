# AgroScout AI Documentation

> **Module**: AgroScout AI Documentation | **Status**: Approved Baseline

Official engineering and product documentation for AgroScout AI - an autonomous edge IoT and computer vision platform for agricultural scouting and crop disease diagnosis.

## Project Summary

AgroScout AI combines edge IoT scouting devices (rovers/drones/fixed stations), deep learning for real-time foliar disease detection, an LLM-powered agronomic assistant, and an offline-first Flutter mobile application.

## Repository Structure

- `01-Product-Requirements-Document-PRD`: Product requirements, personas, and feature specifications
- `02-System-Design-Document-SDD`: System architecture, database schemas, and API contracts
- `03-Module-Technical-Specifications`: Deep-dive technical specifications across AI, Flutter, Backend, and Embedded
- `04-Project-Management-Plan`: Project management, roadmaps, and sprint guidelines

- `06-UX-UI-Design-Documentation`: Design tokens, wireframes, and mobile interface design
