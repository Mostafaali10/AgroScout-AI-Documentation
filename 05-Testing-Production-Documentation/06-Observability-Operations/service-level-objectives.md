# Service Level Objectives (SLOs) & SLAs

> **Module**: Project Management & QA | **Status**: Approved Baseline

Formal commitments for uptime, diagnostic speed, and data durability.

## SLO Commitments

- API Availability: 99.9% uptime per calendar month.
- Diagnosis Speed: 95% of cloud AI diagnoses complete within 500ms.
- Sensor Data Durability: 99.999% durability across all ingested samples.
