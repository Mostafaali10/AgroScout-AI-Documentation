# Crop Disease Detection Model Specification

> **Module**: Technical Specifications | **Status**: Approved Baseline

Deep learning model architecture, backbone selections, and detection heads.

## Model Topology

YOLOv11 object detection with decoupled classification and bounding-box regression heads. Supports 38 disease categories including Early/Late Blight, Powdery Mildew, Leaf Rust, and Bacterial Spot.
