# AI System Architecture Overview

> **Module**: Technical Specifications | **Status**: Approved Baseline

Architectural overview of vision models, sensor fusion networks, and LLM agronomic agents.

## AI Vision Pipeline

Dual-tier vision architecture utilizing lightweight YOLOv8n / YOLOv11n for real-time mobile/edge detection, and high-capacity ConvNeXt-Base ensembles on cloud GPU clusters for secondary verification.

## Multimodal RAG Agent

Agronomic diagnostic assistant powered by fine-tuned open-source LLMs coupled with vector embeddings of plant pathology manuals.
