# MVP Feature Specifications

> **Module**: AgroScout AI PRD | **Status**: Approved Baseline

Detailed functional scope for the Minimum Viable Product release.

## MVP Scope

1. User authentication with JWT and phone OTP.
2. Farm and parcel boundary polygon creation via mobile map.
3. Camera capture with on-device TFLite/ONNX disease classification.
4. Sensor telemetry dashboard showing recent temperature, humidity, and soil moisture readings.
5. Automated offline database sync using local SQLite/Hive database.
