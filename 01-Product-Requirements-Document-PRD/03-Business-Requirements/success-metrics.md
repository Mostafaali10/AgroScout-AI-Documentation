# Product Success Metrics (KPIs)

> **Module**: AgroScout AI PRD | **Status**: Approved Baseline

Key performance indicators measured across product adoption, operational impact, and model accuracy.

## Key Performance Indicators

| Metric Category | KPI | Target Baseline |
| :--- | :--- | :--- |
| **Model Performance** | Disease Detection Top-1 Accuracy | >= 95.0% |
| **Model Latency** | Mobile / Edge On-Device Inference | <= 250 ms |
| **Scouting Efficiency** | Area covered per hour by scouting drone/rover | >= 5 Hectares/hr |
| **System Reliability** | Offline-to-Cloud Sync Success Rate | >= 99.8% |
| **Agronomic Impact** | Average reduction in pesticide spend | >= 25% |
