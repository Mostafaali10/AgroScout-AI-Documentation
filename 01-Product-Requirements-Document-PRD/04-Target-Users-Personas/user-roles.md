# User Roles & Permissions

> **Module**: AgroScout AI PRD | **Status**: Approved Baseline

Role-Based Access Control (RBAC) definition across the AgroScout platform.

## Role Hierarchy

1. **Super Admin**: System maintenance, global model deployments, tenant management.
2. **Farm Owner / Manager**: Farm setup, sensor configuration, team management, billing.
3. **Agronomist**: Mission scheduling, diagnosis review, treatment plan approval.
4. **Scout / Operator**: Mobile scouting, photo capture, edge rover deployment.
