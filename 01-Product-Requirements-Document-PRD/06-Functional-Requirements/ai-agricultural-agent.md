# FR-07: AI Agricultural Advisor Agent

> **Module**: AgroScout AI PRD | **Status**: Approved Baseline

Requirements for the conversational agronomic assistant powered by LLM and RAG.

## Requirements

1. The AI Agent shall answer agronomic queries using retrieval augmented generation over verified plant pathology textbooks.
2. The Agent shall incorporate current sensor data (e.g. high humidity) when suggesting fungal treatment strategies.
3. The Agent shall support multi-turn dialogues in English and Arabic.
