# User Stories Catalog

> **Module**: AgroScout AI PRD | **Status**: Approved Baseline

Comprehensive list of user stories across all product epics.

## Epics & Stories

### Epic 1: Crop Disease Scouting
- **US-101**: As a scout, I want to photograph a diseased plant leaf and receive immediate identification, so I know which disease is threatening the field.
- **US-102**: As an agronomist, I want to view a map with color-coded disease hotspots, so I can plan targeted localized spraying.

### Epic 2: IoT & Microclimate
- **US-201**: As a farmer, I want to monitor soil moisture at 15cm and 45cm depths, so I only irrigate when necessary.
- **US-202**: As an agronomist, I want alerts when humidity stays above 90% for >6 hours, indicating severe fungal risk.
