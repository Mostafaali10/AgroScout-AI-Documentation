# Typography Hierarchy & Font System

> **Module**: UX/UI Design & Research | **Status**: Approved Baseline

Type scales using Inter for Latin scripts and Cairo for Arabic localization.

## Type Scales

- Display Large: 32sp / Bold (Dashboard metrics)
- Headline Medium: 20sp / SemiBold (Screen titles)
- Body Medium: 14sp / Regular (Descriptions & telemetry cards)
- Label Small: 11sp / Medium (Map pins & timestamps)
