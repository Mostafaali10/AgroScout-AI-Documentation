# Reusable UI Component Library

> **Module**: UX/UI Design & Research | **Status**: Approved Baseline

Standardized UI widgets across the AgroScout mobile and web applications.

## Component Inventory

- **HealthScoreGauge**: Circular percentage gauge indicating parcel health.
- **DiseaseResultCard**: Displays leaf photo, pathogen badge, confidence chip, and treatment button.
- **SensorMiniSparkline**: Interactive 24-hour micro-chart for moisture and temperature.
- **SyncStatusChip**: Visual indicator: Synced (Green), Syncing (Blue pulse), Offline (Grey).
