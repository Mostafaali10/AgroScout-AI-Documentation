# Contributing Guidelines

> **Module**: AgroScout AI Documentation | **Status**: Approved Baseline

Guidelines for contributing documentation, architectural updates, and technical proposals to the AgroScout AI project.

## Documentation Standards

All markdown files must follow semantic heading hierarchy, include metadata headers, and link related design documents.

## Workflow

1. Fork or branch from main
2. Create technical documentation following templates in `08-Shared-Templates`
3. Validate cross-links and submit a Pull Request with a clear description.
